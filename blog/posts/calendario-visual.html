Calendário Visual

Crie um calendário para colorir cada dia cumprido.

Materiais necessários

Cartolina branca, canetas coloridas, lápis de cor, adesivos, régua, tesoura, cola, imagens religiosas recortadas.

Como criar

Desenhe 40 quadrados (ou 50 para Páscoa) na cartolina. Numere de 1 a 40. Em cada quadrado, escreva uma ação (ex: 'Rezar um Pai Nosso', 'Ajudar alguém'). Deixe espaço para colorir ao final do dia.

Como usar

Ao final de cada dia, a criança pinta o quadrado correspondente. Para dias especiais (domingos), use adesivos dourados. Ao completar a semana, ganha uma recompensa simbólica.

Dicas

  • ✨ Use cores diferentes para cada semana (roxo, rosa, vermelho, branco)
  • ✨ Inclua símbolos religiosos em datas especiais
  • ✨ Faça um calendário digital no celular para complementar
